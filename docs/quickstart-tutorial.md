# Getting Started

The maintained walkthrough is now in the **[README Quick Start](../README.md#quick-start)**.

Follow it for the complete workflow:

1. Start the app and select a usable host port.
2. Prepare your own layout or choose the supplied example display.
3. Import a song, finish analysis, review timing, and confirm themes.
4. Generate and download the `.xsqz` ZIP package.
5. Extract the archive and prepare a matching xLights show folder.
6. Relink music and external assets, render, preview, and save in xLights.

The README includes macOS extraction instructions and explains the layout
XML, controller/network XML, and generated Power Groups. The earlier UI
tutorial has been replaced by this link so there is one maintained set of
getting-started instructions.
